Your first inspection

  1. Check the connection. This checks the paired service only. It does not open or change a workbook.
  2. Confirm your approved workspace. Workiva access must be provisioned separately. A connected service is not proof of workbook access.
  3. Inspect a selected cell. In an approved Workiva spreadsheet, select a cell, open Wingman and choose Inspect. Refresh an existing tab after installing or reloading the extension.

No panel on the current page? You can always return here through Wingman’s Extension options in Chrome.

What can Wingman access?

Wingman reads selected-cell context on Workiva pages and sends requests through the paired service. For the private VPS setup, that traffic leaves this device through an encrypted SSH connection.

This build also requests Chrome’s broad debugger permission for cell navigation and screenshots. Chrome warns that it can read and change data on all websites. A read-only backend does not remove this browser capability.

No Workiva password or service token belongs on this page. The paired package holds its service configuration; Workiva credentials stay on the backend.
